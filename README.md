## What This Tool Does

- Look up wallet addresses and transaction details
- Search transactions by hash, block or address
- Multi-chain support (Ethereum, BSC, Polygon, Solana)
- View transaction history and token transfers
- View block details and network status
- Real-time data from multiple explorers
- Bookmarks for frequently used addresses
- Works on Windows 10 and Windows 11

Blockchain Explorer Desktop Tool is a professional application for users who need quick access to blockchain data without opening a browser. It provides fast address lookup, transaction search and multi-chain support. This is a fully functional application with no limitations.
